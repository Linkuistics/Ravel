# Result-job completion views

Run `task docs:result-job`, then open
<http://127.0.0.1:8774/#discussion>. The document fills the browser window.
Graph views start at the dark node labelled **Start here**; sequences start
at their first message. Sources remain editable beside the viewer.

- [Ownership → Consumer pairing versus a completion owner](index.html#diagram-ownership) — Marked partial acquisition and native entry/lifetime semantics as distinct unresolved obligations beside the proposed regrouping.
- [Completion and failure → Publication, ending and cleanup join before return](index.html#diagram-settlement) — Corrected syntax and wrapped labels while retaining cleanup, signal joining, outcome precedence and the separate final CLI write.
- [Current completion contract](../../specs/result-job-completion.md) — Recorded the supported joint invariant and the evidence needed for any replacement boundary.

Mermaid 12.0.0 is loaded by the reused static viewer; rendering needs network
access. `task docs:result-job` is the presentation recipe; there are no generated
SVG assets. Existing executable seams and inherited observations are described
by the [component guide](../../components.md). Rendering is not a preservation
or comprehension check.
