# result-job-boundary-k4


## Goal

Compare how a native consumer obtains one opaque result from its own supervised
job after confirmed cleanup, without reconstructing the joint protocol across
result transport, runner ending, cancellation and resource cleanup. Keep the
current composition available. Deliver a supported target contract and separately
assessed working migration route, or a precise bounded observation that would
settle the consequential unknown. This session changes no product code and
selects no implementation tree.
