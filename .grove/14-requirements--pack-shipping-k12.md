# pack-shipping-k12

## Goal

Settle with the owner when the shipping of the packs moves from Grove's
formula to Ravel's formula, and which releases this work causes.

## Context

- Root brief, "Owner decisions still open".
- The decision record `a-caller-transition-publishes-a-versioned-formula-first`.
- The running log of `merge-terms-k15`, on the authoritative copy of each pack.
- The running log of `skill-contract-k22`, on whether Grove needs a change.

## Done when

The running log records the owner's answer to each question below.

- Does Ravel's formula ship the merged packs in this grove's release, or later?
- Does this work cause a Grove release? If it does, how does that release relate
  to the open Grove workstream?
- Which Ravel version is the release, and what do its migration notes cover for
  installed users?
- When do the installed aliases in `share/ravel/skills` point at the merged
  packs?

## Notes

- Bring a recommendation and its evidence to each question.
- The owner has at least one external user, so each release ships migration
  notes.
- The owner's direction is one Ravel package that ships every component. No
  pack needs a release of its own (`merge-terms-k15`).
