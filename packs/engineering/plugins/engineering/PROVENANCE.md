# EngineeringSkills provenance

The skills use independent prose, but several disciplines and examples were
adapted from public prior art. This file keeps the claim-level source keys used
inside `SKILL.md` files without retaining the large point-in-time survey that
originally discovered them.

The section below comes from `plugins/linkuistics/PROVENANCE.md` in Grove. It
covers the one craft skill of this pack that had a section there. The six
`coding-style-*` skills, `simplify-project` and `using-codebase-memory` had no
section there and have none here. The six kind skills are Grove's own text, and
the repository's README names their source.
